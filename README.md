# JR Segurança - Landing Page

Landing page estática para a JR Segurança, com foco em apresentação institucional, serviços de SST e captação de leads.

## Páginas incluídas
- `index.html` — Landing page principal com hero, serviços e formulário de proposta
- `servicos.html` — Painel com principais soluções entregues
- `treinamentos.html` — Catálogo dos treinamentos e NRs atendidos
- `sobre.html` — Propósito, equipe e diferenciais
- `contato.html` — Formulário dedicado e canais diretos

## Estrutura
- Cabeçalho fixo com navegação responsiva e menu mobile
- Componentes reutilizáveis em `assets/css/styles.css` e `assets/js/main.js`
- Branding separado em `assets/css/brand.css` para ajustes rápidos de cores e fontes
- Recursos estáticos (imagens, PDFs e scripts auxiliares) na raiz do projeto

## Como personalizar
1. Atualize textos diretamente nos arquivos `.html`.
2. Ajuste cores, espaçamentos e tipografia nas variáveis de `assets/css/styles.css`.
3. Use `assets/css/brand.css` para sobrescrever a paleta da JR Segurança sem afetar o restante do tema.
4. Substitua as imagens dentro de `assets/img/` mantendo os mesmos nomes ou atualize os caminhos nos HTMLs.

## Hospedagem
- O repositório `jrseguranca.github.io` é publicado via GitHub Pages a partir da raiz (`index.html`).
- O arquivo `CNAME` mantém o domínio personalizado `www.jrseguranca.com`.
